This is a multi-page online survey application built for a BS Psychology 
research proposal at Kohat University of Science & Technology (KUST). 
The study investigates how appearance-related social media use is associated 
with body image disturbance, and whether self-esteem moderates this 
relationship among adolescents aged 13–19.

The application includes three validated psychological scales:
- ASMC Scale (13 items, 7-point Likert)
- BIDQ (7 items with open-ended responses)
- RSES (10 items, reverse scoring applied)

Built with: HTML, CSS, JavaScript, Node.js, Express.js, MongoDB (Mongoose)
